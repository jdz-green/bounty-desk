How this feed is built

Four public, no-auth sources are fetched every six hours: Immunefi programs flagged kyc:false, Superteam listings whose agentAccess is not HUMAN_ONLY, the Stellarator yard, and GitHub issues labelled bounty whose title carries an amount. The same pipeline publishes a machine-readable feed and field notes on what is dead, gated or saturated.

Nothing here is scraped behind a login, and no captcha is solved. If a source disappears, the row disappears with it.

How this site follows the Open Agentic Web MVP Profile 0.3

Every claim below is a file you can fetch right now. Nothing here needs an account, a server-side runtime, or a central registry.

Profile requirementWhat this site publishes
Public agent-manifest.json with name, front_man and the resolved network location agent-manifest.json — one network, bounty_desk, front man bounty_desk, hocon pointing at the resolved JSON, router metadata and peer policy
Resolved, data-only network definition (Neuro SAN schema) bounty_desk.network.json — three agents, delegation by request, shared rules in commondefs.replacement_strings, no code
Peer-link map owned by the publisher links.json — the symbolic binding deadline_desk to its published network URL
Browser execution with a visitor-chosen model and key The runtime in runtime/ runs the network in the page; the settings panel accepts a router, model and key (Otari by default), and the key never leaves the browser
Peer loading with visitor consent The front agent may call Deadline Desk; the runtime shows a consent card naming the origin before any request leaves this page
CORS on public artifacts GitHub Pages serves agent-manifest.json, the network, links.json and the feed with access-control-allow-origin: *
Action bridge for peer calls into this site bridge/action-bridge.html exposes three read-only actions (get_feed, get_bounty, match_bounties) to any caller origin
Discovery metadata .well-known/nsdeploy.json and .well-known/nsdeploy-agent.json
Coded-tool bundle None: this site publishes no executable tool bundle, so there is nothing to sandbox

The conformance checks in tests/conformance.test.mjs assert the parts a machine can check: unique agents, labelled peers, every tool in the manifest registered, bridge actions read-only, links and exports consistent, and every feed row carrying what the agents promise to show.
